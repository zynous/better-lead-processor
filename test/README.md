# Test folder

Local tests for the Lambda handler and LLM mapping: field name variations (camelCase, snake_case, etc.) and unmappable fields → note.

## Files

| File | Purpose |
|------|--------|
| `input-cases.json` | Input test cases: `id`, `description`, `input` (lead payload). Covers firstName/first_name, phone/phoneNumber, postalCode/postal_code, address fields, unmappable → note. |
| `expected-output.json` | Expected mapped output per case (Better CRM shape). Use as reference for comparison. |
| `actual-output.json` | Generated by `run-mapping-tests.js`. Actual LLM-mapped output for each case. |
| `test-local.js` | Run Lambda handler locally (auth, LLM, Better CRM). Use "Debug Handler" in Run and Debug. |
| `run-mapping-tests.js` | Runs each input case through the LLM mapper only (no Lambda, no Better CRM) and writes `actual-output.json`. |

## Prerequisites

- `pnpm build`
- `local-configs/app-config.json` and `local-configs/lice-squad.json`

## Run full handler (single event or one case)

From project root:

```bash
node test/test-local.js              # default event
node test/test-local.js minimal-camel   # case by id
node test/test-local.js 0               # case by index
```

Or: `pnpm run test:local` or `pnpm run test:local:case -- minimal-camel`.

## Run all mapping tests (LLM only)

From project root:

```bash
node test/run-mapping-tests.js
```

Writes `test/actual-output.json`. Or: `pnpm run test:mapping`.

## Compare actual vs expected

```bash
node test/compare-outputs.js
# or: pnpm run test:compare
```

## Compare actual vs expected (details)

Diff `test/actual-output.json` vs `test/expected-output.json` (per-case `output` vs `expected`). Update `expected-output.json` after reviewing actual output to catch regressions later.
